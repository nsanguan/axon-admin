# AXON Admin Documentation

เอกสารภาษาไทยสำหรับการใช้งาน AXON Admin ถูกรวบรวมไว้ในโฟลเดอร์นี้ เพื่อให้ทีมงานเปิดอ่านตามบทบาทและหน้าจอที่เกี่ยวข้องได้ง่ายขึ้น

## คู่มือแนะนำ

- [USER_MANUAL_AXON_ADMIN_TH.md](/u01/axon-admin/docs/USER_MANUAL_AXON_ADMIN_TH.md) — คู่มือรวมทุกหน้าจอหลักของ AXON Admin
- [USER_MANUAL_MCP_AGENTS_TESTING_TH.md](/u01/axon-admin/docs/USER_MANUAL_MCP_AGENTS_TESTING_TH.md) — คู่มือเฉพาะหน้าจอ MCP Agents Testing

## คู่มือตามบทบาท

- [USER_MANUAL_ADMIN_OPERATIONS_TH.md](/u01/axon-admin/docs/USER_MANUAL_ADMIN_OPERATIONS_TH.md) — สำหรับผู้ดูแลระบบและผู้จัดการสิทธิ์
- [USER_MANUAL_AXON_OPERATIONS_TH.md](/u01/axon-admin/docs/USER_MANUAL_AXON_OPERATIONS_TH.md) — สำหรับทีม AXON Operations และทีมปฏิบัติการ
- [USER_MANUAL_QA_UAT_CHECKLIST_TH.md](/u01/axon-admin/docs/USER_MANUAL_QA_UAT_CHECKLIST_TH.md) — สำหรับทีมทดสอบ QA และ UAT

## วิธีเลือกเอกสาร

- หากต้องการภาพรวมของระบบ ให้เริ่มที่ [USER_MANUAL_AXON_ADMIN_TH.md](/u01/axon-admin/docs/USER_MANUAL_AXON_ADMIN_TH.md)
- หากต้องการทดสอบ MCP Inspector โดยตรง ให้เปิด [USER_MANUAL_MCP_AGENTS_TESTING_TH.md](/u01/axon-admin/docs/USER_MANUAL_MCP_AGENTS_TESTING_TH.md)
- หากทำงานตามบทบาทเฉพาะ ให้เลือกคู่มือในหมวด "คู่มือตามบทบาท"
